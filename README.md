
# Placement Preparation & Job Application Tracker

## Overview
A Python-based web application that helps students organize job applications and monitor their placement preparation progress.

## Technologies Used
- Python
- Streamlit
- SQLite
- Pandas

## Features
- Dashboard displaying placement statistics
- Add and manage job applications
- Track application statuses
- Create and manage preparation tasks
- Mark tasks as completed
- Monitor preparation progress
- Export application records as CSV
- Store data using SQLite

## Installation

1. Clone or download this project.
2. Install the dependencies:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py

## Database
SQLite stores job application and preparation task records locally.

## Limitations
- Designed for individual local use.
- No user authentication or cloud synchronization.
